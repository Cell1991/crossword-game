# Test Scenarios — WordX (Crossword Multiplayer)

เอกสารนี้รวม test scenario ของเกมทั้งฝั่ง backend (กติกา, API, turn, HP, การ์ด, realtime, การเปลี่ยนตัวอักษร) และฝั่ง UI
ทุก scenario มีรหัส (เช่น `MV-03`) ซึ่งตรงกับชื่อฟังก์ชันเทสต์อัตโนมัติ (เช่น `test_mv03_...`)

กติกาอ้างอิง: `Unified_Online_Crossword_Rules.md` (เรื่องที่ไม่ได้เขียนไว้ใช้แบบ Letter League ใน Discord) ส่วนที่ยังไม่ได้ทำดูหัวข้อ [กติกาที่ยังไม่ได้ทำ](#กติกาที่ยังไม่ได้ทำ)

## วิธีรันเทสต์อัตโนมัติ

```bash
cd backend
pip install -r requirements.txt
python -m pytest -rxX
```

- `tests/conftest.py` บังคับให้เทสต์ใช้ SQLite ชั่วคราวเสมอ เพราะเทสต์ API จะ drop/create ตารางทุกครั้ง จึงไม่ไปลบข้อมูลใน `crossword.db` หรือ Postgres ใน docker
  (ถ้าต้องการใช้ฐานข้อมูลอื่นที่ทิ้งได้ ให้ตั้ง `TEST_DATABASE_URL`)
- `GameTable` ใน conftest ใช้จัดฉากให้ผลลัพธ์แน่นอน เช่น กำหนดตัวอักษรในแร็ก/ถุง (`set_tiles`), วางตัวอักษรบนกระดาน (`set_board`), ปรับ HP หรือจำนวนเทิร์น
- ผลล่าสุด: **92 passed, 1 xfailed** (xfailed คือ BUG-1 ที่ยังไม่ได้แก้)

สัญลักษณ์: ✅ ผ่าน · ❌ พบบั๊ก (เทสต์เป็น `xfail(strict=True)` จะเปลี่ยนเป็น fail ทันทีเมื่อแก้บั๊กแล้ว ให้ถอด mark ออก) · 🖐 ยังไม่ได้ทดสอบมือ

กระดาน: **19 แถว × 27 คอลัมน์** ดาวกลางอยู่ที่ (9, 13) ช่องพิเศษ (3L 8 ช่อง, 2L 12 ช่อง, ⚡ 8 ช่อง) คือแบบ 15 × 15 เดิมกระจายตามสัดส่วน
ตำแหน่งอยู่ใน `backend/app/game/board.py` และ `frontend/lib/board.ts` (ต้องแก้ให้ตรงกันทั้งสองไฟล์)

## 9. ระบบเปลี่ยนตัวอักษรกับถุง (Exchange)

### กติกา (ตาม §5–6 ของไฟล์กติกา)

- ใช้ได้เฉพาะ **ตาของตัวเอง** เกมต้องอยู่สถานะ `PLAYING` และผู้เล่นต้องมี HP > 0 และไม่ `OFFLINE`
- ถุงต้องเหลือตัวอักษร **อย่างน้อย 7 ตัว** ถึงจะเปลี่ยนได้
- เลือกได้ตั้งแต่ 1 ตัวจนถึงทั้งแร็ก ถ้าขอเปลี่ยนมากกว่าที่ถุงมี (เกิดได้เมื่อแร็กเกิน 7 ตัวจากการ์ด) **นับเป็น pass**
- ระบบ **จั่วตัวใหม่ก่อน** แล้วค่อยใส่ตัวเก่ากลับลงถุงและสับ จึงไม่มีทางจั่วได้ตัวที่เพิ่งคืนไป ตัวใหม่เข้าที่ช่องเดิมของตัวที่ถูกเปลี่ยน
- การเปลี่ยน **เสียตา** ไม่ได้คะแนน ไม่ทำดาเมจ บันทึก move `EXCHANGE` และ **นับเป็นเทิร์นที่ไม่ได้คะแนน** (รวมกับ pass ครบ 4 ครั้งติดกันเกมจบ)
- ถ้าเป็นเทิร์นสุดท้าย (`max_turns`) เกมจบ
- API: `POST /api/games/{game_id}/exchange` header `X-Player-ID`, body `{"tile_ids": ["..."]}` ตอบ `status: "exchanged"` หรือ `"passed"`
- WebSocket: `TILES_EXCHANGED` ส่งแค่ `playerId`, `count`, `nextPlayerId`, `turnNumber` ไม่เปิดเผยว่าเปลี่ยนตัวอะไร

## กติกาที่ยังไม่ได้ทำ

ส่วนต่อไปนี้มีใน `Unified_Online_Crossword_Rules.md` แต่เกมยังไม่รองรับ (บางข้อขัดกับระบบเฉพาะของเกมนี้ เช่น HP การ์ด และช่อง ⚡ ควรตัดสินใจก่อนทำ)

- ตัวอักษรว่าง (blank) 2 ตัว รวมเป็น 100 ตัว — ตอนนี้มี 98 ตัว
- ช่อง Double/Triple Word และดาวกลางนับเป็น Double Word รวมถึงตัวคูณคำซ้อน ×4/×9 — ตอนนี้มีแค่ 2L/3L และ ⚡
- ขนาดกระดาน — ไฟล์กติกาเป็น 15 × 15 แต่ทีมขอ 19 × 27 จึงใช้ 19 × 27
- หักคะแนนตัวอักษรที่เหลือในแร็กตอนจบเกม และโบนัสให้คนที่วางหมดแร็ก
- นาฬิกาแบบหมากรุก 25 นาทีต่อคนและหักคะแนนเมื่อเกินเวลา — ตอนนี้ใช้เวลาต่อตาแบบ casual ตาม §7
- ระบบ challenge — ตอนนี้ตรวจคำอัตโนมัติจึงวางคำผิดไม่ได้ตั้งแต่แรก
- จั่วตัวอักษรเพื่อตัดสินคนเริ่มก่อน — ตอนนี้ host เริ่มก่อน
- เกมจบเมื่อไม่ได้คะแนนครบ 2 ตาต่อคน (เกมมากกว่า 2 คน) หรือกติกา six-zero — ตอนนี้ครบ 4 เทิร์นติดกันเสมอ
- จำนวนผู้เล่นสูงสุด 4 คน — ตอนนี้รับได้ 6 คน
